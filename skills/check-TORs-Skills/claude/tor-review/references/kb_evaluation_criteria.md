9.2 ตัวอย่าง: โครงการพัฒนา Mobile Application (กรณีศึกษา GPF Digital Twins)
ตัวอย่างต่อไปนี้ดึงข้อมูลจาก TOR จริงของกองทุนบำเหน็จบำนาญข้าราชการ (กบข.) โครงการ Digital Twins ปี 2565:
หัวข้อ 1. หลักการและเหตุผล
สำนักงานกองทุนบำเหน็จบำนาญข้าราชการ (กบข.) มีแผนงานยุทธศาสตร์ปี 2565 ที่ต้องการพัฒนาเครื่องมือ "คู่แฝดดิจิทัล" (Digital Twins) สำหรับช่วยสมาชิกในการประมวลความคิด วิเคราะห์ และตัดสินใจด้านการออมและลงทุน โดยพัฒนาเป็น Mobile Application และปรับปรุงระบบ My GPF Application
หัวข้อ 2. คุณสมบัติของผู้ยื่นข้อเสนอ
มีผู้เชี่ยวชาญด้าน UI/UX Design ที่มีทักษะสูง
มีผู้เชี่ยวชาญด้านพัฒนา Mobile Application ทั้ง iOS และ Android
มีความสามารถในการสร้างแบบจำลองทางการเงิน (Financial Simulation Model)
หัวข้อ 3. ขอบเขตงาน (สรุป)
แบ่งเป็น 3 ระยะ:
ระยะที่ 1 (60 วัน): ปรับปรุง UI/UX การเลือกแผนการลงทุน, เชื่อมต่อ Chatbot, พัฒนาระบบ App Ratings และออกแบบ System Architecture
ระยะที่ 2 (135 วัน): พัฒนาโปรแกรม Digital Twins ทั้ง 3 ตัว (MySelf, My Wish, My DA) พร้อม Dashboard เปรียบเทียบ
ระยะที่ 3 (225 วัน): พัฒนาระบบ GPF Together แบบ Gamification และเครื่องมือสำหรับเจ้าหน้าที่
หัวข้อ 4. ข้อกำหนดทางเทคนิคที่สำคัญ
ระบบต้องเรียกค้นข้อมูลสมาชิกได้ภายใน 6 วินาที
รองรับ Android 7 ขึ้นไป, iOS 12 ขึ้นไป, Huawei HarmonyOS 2.0 ขึ้นไป
ข้อมูล Sensitive Information ต้องเข้ารหัสด้วย AES-256
การส่งข้อมูลต้องใช้ TLS 1.2 (SHA-2 2048 bit) ขึ้นไป
รองรับ 2-Factor Authentication
Source Code ต้องผ่านการตรวจสอบด้วย HP Fortify และแก้ไขช่องโหว่ Medium ขึ้นไปทั้งหมด
หัวข้อ 5. การรับประกัน
รับประกันไม่น้อยกว่า 1 ปีนับจากวันตรวจรับงาน
แก้ไข Bug ภายใน 1 วัน
มีช่องทางรับแจ้งทุกวันทำการ ทั้งโทรศัพท์และ Email
ตอบกลับภายใน 4 ชั่วโมงหลังรับแจ้ง

การจ้างออกแบบรวมก่อสร้างตามระเบียบฯ ข้อ 82
หน่วยงานของรัฐใดประสงค์จะจัดท าโครงการจ้างออกแบบรวมก่อสร้าง ที่มีรูปแบบ และขอบเขตการ
ด าเนินงานครอบคลุมการส ารวจ ออกแบบ ตลอดจนก่อสร้างจนแล้วเสร็จสมบูรณ์ รวมทั้งการบ ารุงรักษาในช่วง
เริ่มต้นของโครงการโดยผู้รับจ้างเพียงรายเดียว ให้เสนอโครงการต่อคณะรัฐมนตรี เพื่อขอความเห็นชอบก่อนที่จะ
เริ่มต้นด าเนินโครงการ
การจ้างออกแบบรวมก่อสร้างสามารถด าเนินการได้ 3 รูปแบบ ดังนี้
(1) จ้างออกแบบควบคู่การก่อสร้าง ( Design & Build Project) คือ โครงการที่มีวงเงินลงทุน และ
เทคโนโลยีด าเนินการสูง รวมทั้งสามารถจัดท าโครงการได้หลายรูปแบบ โดยส่วนใหญ่จะเป็นโครงการใหม่ที่ไม่เคย
มีการด าเนินการมาก่อนในประเทศ ดังนั้น จึงมีความจ าเป็นต้องใช้ผู้รับเหมาด าเนินโครงการที่มีความรู้
ความสามารถ และเทคนิคในการด าเนินการพิเศษ โดยเฉพาะการช าระเงินค่าด าเนินโครงการจะมีรูปแบบ การจ่าย
ช าระเงินตามความก้าวหน้าของงานเป็นงวด ๆ (installment)
(2) จ้างก่อสร้างพร้อมจัดหาเงินทุน (Turnkey Project) คือ โครงการที่ผู้ว่าจ้างจะจัดหา ผู้รับจ้างด าเนิน
โครงการจนแล้วเสร็จ จึงจะมีการช าระเงินค่าด าเนินโครงการ ซึ่งผู้รับจ้างอาจต้องมีหน้าที่ในการจัดหาแหล่งเงินทุน
เพื่อด าเนินโครงการด้วย รวมทั้งผู้ว่าจ้างต้องมีวงเงินด าเนินโครงการอ้างอิงได้ประกอบการพิจารณาโครงการ
(Reference Based Price)
(3) จ้างออกแบบควบคู่ก่อสร้างพร้อมจัดหาเงินทุน (หรือจ้างเหมาแบบเบ็ดเสร็จเต็มรูปแบบ) คือ
โครงการที่ใช้รูปแบบด าเนินโครงการทั้ง 2 รูปแบบ โดยผู้รับจ้างเป็นผู้ออกแบบและก่อสร้างควบคู่กัน ( Design &
Build) รวมทั้งท าหน้าที่จัดหาเงินทุนด าเนินโครงการ ซึ่งผู้ว่าจ้างจะช าระเงินค่าด าเนินโครงการเมื่อแล้วเสร็จ
หลักเกณฑ์ วิธีการ และรายละเอียดกระบวนและขั้นตอนการจ้างออกแบบรวมก่อสร้าง ให้เป็นไปตามที่
กรมบัญชีกลางก าหนดโดยความเห็นขอบของคณะกรรมการนโยบาย
