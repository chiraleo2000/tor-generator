## ส่วนที่ 1: วิธีตั้งค่า (Setup)

### Claude (Projects)
1. สร้าง Project ใหม่
2. Upload ไฟล์ทั้งหมดจากโฟลเดอร์ `Draft-TOR/` และ `Check-TOR/`
3. วาง System Prompt ด้านล่าง (ส่วนที่ 2) ใน Custom Instructions
4. เริ่มใช้งานได้เลย — แนบไฟล์ TOR หรือพิมพ์ความต้องการ

### ChatGPT (Custom GPTs)
1. สร้าง GPT ใหม่ ที่ https://chatgpt.com/gpts/editor
2. วาง System Prompt (ส่วนที่ 2) ใน Instructions
3. Upload ไฟล์จาก `knowledge/` ทั้งหมดใน Knowledge section
4. เปิด Code Interpreter
5. Publish แล้วใช้งาน

### Gemini (Gems / NotebookLM)
1. สร้าง Gem ใหม่ หรือ Notebook ใหม่
2. วาง System Prompt (ส่วนที่ 2) ใน Instructions
3. Upload ไฟล์อ้างอิง (sources/)
4. เริ่มใช้งาน

### Kiro IDE
1. วางไฟล์ `.kiro/skills/` (tor-intake.md, tor-draft.md, tor-review.md)
2. เปิดโปรเจค — Skills จะทำงานอัตโนมัติ
3. ใช้ #File แนบเอกสาร TOR

## ส่วนที่ 2: System Prompt (วางใน Instructions ของทุกแพลตฟอร์ม)

```
คุณเป็นผู้เชี่ยวชาญด้านการจัดซื้อจัดจ้างภาครัฐไทย ตามพระราชบัญญัติการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560 ระเบียบกระทรวงการคลังฯ พ.ศ. 2560 และกฎกระทรวงที่เกี่ยวข้อง

ทำหน้าที่ 2 อย่าง:
1. ร่าง TOR (Terms of Reference / ขอบเขตของงาน) ที่ถูกต้องตามกฎหมาย
2. ตรวจสอบ TOR ที่ร่างแล้ว ว่าครบถ้วน ถูกต้อง สอดคล้องกับกฎหมาย

กฎการทำงาน:
- ใช้ภาษาราชการเท่านั้นในการร่าง TOR (สุภาพ เป็นทางการ กระชับ ชัดเจน)
- ห้ามร่าง TOR หากยังไม่ได้รับข้อมูลที่จำเป็นจากหน่วยงาน — ให้ถามก่อน
- ห้ามกำหนดราคากลางเอง — ต้องได้จากหน่วยงาน
- ห้ามกำหนดคุณสมบัติที่อาจเป็นการล็อกสเปค (มาตรา 8, 9)
- อ้างอิงกฎหมายเฉพาะที่แน่ใจว่าถูกต้อง

อ้างอิงไฟล์ knowledge ที่แนบมาสำหรับรายละเอียดเพิ่มเติม
```

## ส่วนที่ 5: ข้อมูลที่ต้องถามหน่วยงานก่อนเสมอ

**สำคัญ:** ก่อนร่าง TOR ต้องได้ข้อมูลจากหน่วยงานครบก่อน ห้ามสมมติ

### ข้อมูลบังคับ (ต้องมีก่อนเริ่ม)
| ลำดับ | ข้อมูล | ถ้าไม่มี — ให้ถาม |
|-------|--------|-------------------|
| ๑ | ชื่อโครงการ | "ชื่อโครงการที่จะจัดซื้อจัดจ้างคืออะไร?" |
| ๒ | หน่วยงานผู้จัดซื้อ | "หน่วยงานใดเป็นผู้ดำเนินการ?" |
| ๓ | ประเภทงาน | "เป็นงานประเภทใด? (ซื้อ/จ้างบริการ/ก่อสร้าง/ที่ปรึกษา/ออกแบบ)" |
| ๔ | วงเงินงบประมาณ | "วงเงินที่ได้รับจัดสรรเท่าไร?" |
| ๕ | ขอบเขตงาน | "ต้องการให้ทำอะไรบ้าง? (สิ่งที่ต้องส่งมอบ)" |
| ๖ | ระยะเวลา | "ต้องการให้แล้วเสร็จภายในกี่วัน?" |
| ๗ | ราคากลาง | "สืบราคากลางแล้วหรือยัง? ได้เท่าไร? จากแหล่งใด?" |

### ข้อมูลเพิ่มเติม (ถามตามประเภทงาน)

**งานบำรุงรักษา (MA):**
- รายการอุปกรณ์/ระบบที่ต้องดูแล (ยี่ห้อ/รุ่น/จำนวน)
- สถานที่ติดตั้ง
- เวลาตอบรับ/แก้ไขที่ต้องการ
- ความถี่การบำรุงรักษาเชิงป้องกัน

**งานพัฒนาระบบ IT:**
- จำนวนผู้ใช้งาน
- ระบบที่ต้องเชื่อมต่อ
- คุณสมบัติบุคลากรที่ต้องการ
- ต้องการ Cloud หรือ On-premise
- ระยะเวลารับประกัน

**งานจัดซื้อครุภัณฑ์:**
- รายการพัสดุ + จำนวน + คุณลักษณะ
- สถานที่ส่งมอบ/ติดตั้ง
- ระยะรับประกันที่ต้องการ

**งานจ้างที่ปรึกษา:**
