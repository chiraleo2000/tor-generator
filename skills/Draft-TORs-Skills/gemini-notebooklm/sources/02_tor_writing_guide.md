# คู่มือการเขียน TOR ด้วยภาษาราชการ

## หลักการสำคัญ
1. ใช้ภาษาราชการที่สุภาพ เป็นทางการ กระชับ ชัดเจน ไม่กำกวม
2. ใช้คำศัพท์ทางกฎหมาย/ราชการ
3. ใช้ประโยคสมบูรณ์ มีประธาน กริยา กรรม
4. ห้ามใช้ภาษาพูด ภาษาปาก คำย่อไม่เป็นทางการ

## ตารางคำศัพท์ราชการ

| ใช้ (ถูกต้อง) | ห้ามใช้ (ไม่เป็นทางการ) |
|--------------|------------------------|
| ดำเนินการ | ทำ |
| จัดซื้อจัดจ้าง | ซื้อ/จ้าง |
| ผู้ยื่นข้อเสนอ | ผู้ขาย/ร้าน |
| กำหนดส่งมอบ | เดดไลน์ |
| ให้แล้วเสร็จภายใน | ต้องเสร็จใน |
| เป็นจำนวนเงินทั้งสิ้น | รวมเป็นเงิน |
| พัสดุ | ของ/สิ่งของ |
| ผู้รับจ้าง | ผู้รับเหมา |
| คณะกรรมการตรวจรับพัสดุ | กรรมการรับของ |
| มีความประสงค์จะ | ต้องการจะ |
| ตามที่ได้รับอนุมัติ | ตามที่ OK แล้ว |
| จำนวน X รายการ | X อย่าง |
| คุณลักษณะเฉพาะ | สเปค |
| งบประมาณ | เงิน/ตังค์ |
| ผู้มีอำนาจ | หัวหน้า/บอส |

## สำนวนมาตรฐาน

### เปิดต้น TOR:
"ด้วย [ชื่อหน่วยงาน] มีความประสงค์จะ [จัดซื้อ/จัดจ้าง] [ชื่อโครงการ] โดยวิธี [วิธีจัดซื้อ] เป็นจำนวนเงินทั้งสิ้น [จำนวนเงิน] บาท ([ตัวอักษร]) รวมภาษีมูลค่าเพิ่มและค่าใช้จ่ายทั้งปวงแล้ว"

### ระบุระยะเวลา:
"ผู้รับจ้างต้องดำเนินการให้แล้วเสร็จภายในระยะเวลา [จำนวน] วัน นับถัดจากวันลงนามในสัญญา"

### ค่าปรับ:
"หากผู้รับจ้างไม่สามารถส่งมอบงาน/พัสดุได้ตามกำหนด ผู้รับจ้างจะต้องชำระค่าปรับเป็นรายวัน ในอัตราร้อยละ [X] ของราคา [สิ่งที่ยังไม่ส่งมอบ/ราคางานทั้งหมด]"

### อ้างอิงกฎหมาย:
"ตามพระราชบัญญัติการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. ๒๕๖๐ มาตรา [XX]"

### คำเชื่อม:
- ทั้งนี้ (furthermore/provided that)
- เว้นแต่ (unless/except)
- โดยอนุโลม (mutatis mutandis)
- อนึ่ง (moreover)
- เพื่อให้เป็นไปตาม (in compliance with)
- ตามที่กำหนดไว้ (as specified)

### ข้อห้าม:
"ผู้รับจ้างจะนำงานไปจ้างช่วงให้ผู้อื่นทำแทนมิได้"

## การใช้ตัวเลข
- เลขไทย (๑)(๒)(๓) — อ้างข้อกฎหมาย, มาตรา
- เลขอารบิก 1. 2. 3. — หัวข้อ TOR, รายการทั่วไป
- วงเงิน: ใช้ทั้งตัวเลขและตัวอักษร เช่น "500,000 บาท (ห้าแสนบาทถ้วน)"
- เปอร์เซ็นต์: "ร้อยละ 5" (ไม่ใช่ "5%")

4. ขอบเขตของงาน
5. ระยะเวลาดำเนินการ
6. วงเงินงบประมาณ
7. สถานที่ส่งมอบ/ดำเนินการ
8. การส่งมอบและตรวจรับ
9. การรับประกัน
10. อัตราค่าปรับ
11. หลักประกัน
12. เงื่อนไขอื่นๆ
13. เกณฑ์การพิจารณาข้อเสนอ
