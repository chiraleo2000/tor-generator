# กฎการเลือกวิธีจัดซื้อจัดจ้าง (Decision Rules)

อ้างอิง: พ.ร.บ. การจัดซื้อจัดจ้างฯ 2560 มาตรา 55-56, กฎกระทรวงกำหนดวงเงิน

## หลักการ
มาตรา 56 วรรคแรก: "ให้ใช้วิธีประกาศเชิญชวนทั่วไปก่อน เว้นแต่เข้าเงื่อนไขข้อยกเว้น"

## ขั้นตอนที่ 1: เลือกวิธีหลัก

| ID | เงื่อนไข | ผลลัพธ์ (วิธีจัดซื้อ) | อ้างอิง |
|----|----------|----------------------|---------|
| R1 | วงเงินไม่เกิน 500,000 บาท | เฉพาะเจาะจง | กฎกระทรวง + ม.56(2)(ข) |
| R2 | วงเงินเกิน 500,000 + ไม่มีเงื่อนไขพิเศษ | ประกาศเชิญชวนทั่วไป | ม.55(1), 56 วรรคแรก |
| R3 | ประกาศแล้วไม่มีผู้ยื่น/ไม่ได้ผล | คัดเลือก | ม.56(1)(ก) |
| R4 | คุณลักษณะเฉพาะ/ฝีมือเฉพาะ | คัดเลือก | ม.56(1)(ข) |
| R5 | จำเป็นเร่งด่วน (ไม่ใช่ฉุกเฉิน) | คัดเลือก | ม.56(1)(ค) |
| R6 | ต้องระบุยี่ห้อเฉพาะ | คัดเลือก | ม.56(1)(ง) |
| R7 | ซื้อจากต่างประเทศ/ทุนต่างประเทศ | คัดเลือก | ม.56(1)(จ) |
| R8 | ฉุกเฉินถึงชีวิต/ทรัพย์สิน/ภัยพิบัติ | เฉพาะเจาะจง | ม.56(2)(ค) |
| R9 | ผู้ขาย/ผู้ให้บริการรายเดียว | เฉพาะเจาะจง | ม.56(2)(ง) |
| R10 | ซื้อ/จ้างหน่วยงานรัฐ/รัฐวิสาหกิจ | เฉพาะเจาะจง | ม.56(2)(จ) |

## ขั้นตอนที่ 2: เลือกวิธีย่อย (กรณีประกาศเชิญชวนทั่วไป)

| เงื่อนไข | วิธีย่อย |
|----------|---------|
| พัสดุอยู่ใน e-catalog + วงเงิน 500,001-5,000,000 | e-market (ใบเสนอราคา) |
| พัสดุอยู่ใน e-catalog + วงเงิน > 5,000,000 | e-market (ประมูลอิเล็กทรอนิกส์) |
| พัสดุไม่อยู่ใน e-catalog OR เทคนิคเฉพาะ + วงเงิน > 500,000 | e-bidding |
| พื้นที่ไม่มีสัญญาณ internet + วงเงิน 500,001-5,000,000 | สอบราคา |

## ขั้นตอนที่ 3: ตรวจสอบเงื่อนไขเพิ่มเติม

### สำหรับวิธีคัดเลือก:
- ต้องมีเหตุผลเป็นลายลักษณ์อักษร
- เชิญผู้ประกอบการไม่น้อยกว่า 3 ราย (ถ้ามี)
- บันทึกขออนุมัติต่อหัวหน้าหน่วยงาน

### สำหรับวิธีเฉพาะเจาะจง (กรณีพิเศษ > 500,000):
- ต้องจัดทำรายงานขอซื้อ/จ้าง
- ต้องมีเหตุผลและความจำเป็น
- ราคากลางต้องเปิดเผย

## ตัวอย่างการใช้งาน

ตัวอย่าง 1: "จ้างพัฒนาระบบ IT วงเงิน 2,000,000 บาท"
→ วงเงิน > 500,000 + ไม่มีเงื่อนไขพิเศษ → R2 → ประกาศเชิญชวนทั่วไป
→ ไม่อยู่ใน e-catalog + มีเทคนิคเฉพาะ → e-bidding

ตัวอย่าง 2: "ซื้อกระดาษ A4 วงเงิน 30,000 บาท"
→ วงเงิน <= 500,000 → R1 → เฉพาะเจาะจง

ตัวอย่าง 3: "จ้างที่ปรึกษาออกแบบระบบ วงเงิน 5,000,000 บาท"
→ วงเงิน > 500,000 + คุณลักษณะเฉพาะ (ที่ปรึกษา) → R4 → คัดเลือก
