# Checklist ตรวจสอบ TOR จัดซื้อจัดจ้างภาครัฐ

## หมวด A: ข้อมูลพื้นฐาน (Basic Information)
- [ ] A1: ชื่อโครงการครบถ้วน ชัดเจน
- [ ] A2: หน่วยงานจัดซื้อระบุชัดเจน
- [ ] A3: วงเงินงบประมาณ (ตัวเลข + ตัวอักษร)
- [ ] A4: ระบุ "รวมภาษีมูลค่าเพิ่มและค่าใช้จ่ายทั้งปวงแล้ว"
- [ ] A5: วิธีจัดซื้อจัดจ้างสอดคล้องกับวงเงิน
- [ ] A6: อ้างอิง พ.ร.บ./ระเบียบ ถูกต้อง
- [ ] A7: ระบุเหตุผลความจำเป็น (ในกรณีคัดเลือก/เฉพาะเจาะจง)

## หมวด B: ขอบเขตงาน (Scope of Work)
- [ ] B1: ขอบเขตงานชัดเจน ไม่กำกวม
- [ ] B2: ไม่ล็อกสเปค/เอื้อผู้ประกอบการรายใด (ม.9)
- [ ] B3: ระบุปริมาณ/หน่วยนับครบ
- [ ] B4: มาตรฐานวัสดุ/งาน อ้างอิงได้ (ถ้ากำหนด)
- [ ] B5: สถานที่ส่งมอบ/ดำเนินการ ระบุชัดเจน
- [ ] B6: ไม่มีข้อกำหนดที่เกินจำเป็น
- [ ] B7: ไม่ระบุยี่ห้อโดยไม่มีเหตุผล (หรือใช้ "หรือเทียบเท่า")
- [ ] B8: ระบุผลงานส่งมอบ (deliverables) ครบถ้วน

## หมวด C: ระยะเวลา (Timeline)
- [ ] C1: ระยะเวลาดำเนินการ (จำนวนวัน)
- [ ] C2: ใช้สำนวน "นับถัดจากวันลงนามในสัญญา"
- [ ] C3: กำหนดส่งมอบ/งวดงาน (ถ้าแบ่งงวด)
- [ ] C4: ระยะเวลาตรวจรับ
- [ ] C5: ระยะเวลาสอดคล้องกับลักษณะ/ขนาดงาน
- [ ] C6: ไม่สั้นจนเป็นข้อจำกัดเกินไป

## หมวด D: ค่าปรับและหลักประกัน (Penalty & Guarantee)
- [ ] D1: อัตราค่าปรับรายวัน อยู่ในช่วง 0.01-0.20%
- [ ] D2: ค่าปรับขั้นต่ำ 100 บาท/วัน
- [ ] D3: ฐานคำนวณค่าปรับถูกต้อง (รวม/แยกส่วน)
- [ ] D4: หลักประกันสัญญา 5% ของวงเงินสัญญา
- [ ] D5: หลักประกันผลงาน (ถ้ามี)
- [ ] D6: เงื่อนไขบอกเลิกสัญญาชัดเจน
- [ ] D7: การรับประกัน (ระยะเวลาสมเหตุสมผล)

## หมวด E: คุณสมบัติผู้ยื่นข้อเสนอ (Qualifications)
- [ ] E1: คุณสมบัติพื้นฐานตามกฎหมาย (6 ข้อ) ครบ
- [ ] E2: ไม่กีดกันโดยไม่มีเหตุผล
- [ ] E3: ผลงานย้อนหลังสมเหตุสมผล (ไม่เกินจำเป็น)
- [ ] E4: ใบอนุญาตวิชาชีพ (ถ้าจำเป็นตามกฎหมาย)
- [ ] E5: ทุนจดทะเบียน (ถ้ากำหนด ต้องมีเหตุผล)
- [ ] E6: เกณฑ์การพิจารณาสอดคล้องกับประเภทพัสดุ
- [ ] E7: ไม่กำหนดประสบการณ์/ผลงานเฉพาะเจาะจงเกินไป

## การประเมินผล
- ผ่านทุกข้อ: TOR พร้อมใช้
- ไม่ผ่าน 1-3 ข้อ (ไม่ร้ายแรง): แก้ไขเล็กน้อย
- ไม่ผ่าน > 3 ข้อ หรือไม่ผ่านข้อร้ายแรง (B2, E2): ต้องปรับปรุงใหม่

## ข้อร้ายแรง (Critical - ต้องแก้ไขทันที)
- B2: ล็อกสเปค/เอื้อผู้ประกอบการ
- E2: กีดกันผู้ประกอบการ
- A5: วิธีจัดซื้อไม่สอดคล้องกับวงเงิน
- D1: ค่าปรับเกินอัตราที่กฎหมายกำหนด
