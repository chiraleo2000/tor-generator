# Template Selection Matrix

## ประเภทพัสดุ x วิธีจัดซื้อ = Template

### สินค้า
- ประกาศเชิญชวน: TOR-G-INV (+ คุณลักษณะเฉพาะ, สถานที่ส่งมอบ, รับประกัน)
- เฉพาะเจาะจง: TOR-G-SPE (+ คุณลักษณะเฉพาะ, เหตุผล)

### งานบริการ
- ประกาศเชิญชวน: TOR-S-INV (+ SLA, KPI, บุคลากร, เกณฑ์ตรวจรับ)
- เฉพาะเจาะจง: TOR-S-SPE (+ SLA, เกณฑ์ตรวจรับ)

### ก่อสร้าง
- ประกาศเชิญชวน: TOR-C-INV (+ BOQ, แบบรูป, ผู้ควบคุมงาน, มาตรฐานวัสดุ)

### ที่ปรึกษา
- คัดเลือก: TOR-CON-SEL (+ คุณสมบัติทีม, ผลงาน, เกณฑ์คุณภาพ >= 80%)

### ออกแบบ/ควบคุม
- คัดเลือก: TOR-D-SEL (+ ใบอนุญาตวิชาชีพ, ค่าจ้างตามกฎกระทรวง 2562)

### เช่า
- เฉพาะเจาะจง: TOR-L-SPE (+ เงื่อนไขบำรุงรักษา, ส่งคืน)

## เกณฑ์การพิจารณา
- สินค้า/บริการทั่วไป: เกณฑ์ราคาต่ำสุด
- ที่ปรึกษา: คุณภาพ >= 80% + ราคา
- งานซับซ้อน: ราคาประกอบเกณฑ์อื่น
