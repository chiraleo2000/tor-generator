# กฎการเลือกวิธีจัดซื้อจัดจ้าง

อ้างอิง: พ.ร.บ. การจัดซื้อจัดจ้างฯ 2560 มาตรา 55-56

## หลักการ
มาตรา 56: ให้ใช้วิธีประกาศเชิญชวนทั่วไปก่อน เว้นแต่เข้าเงื่อนไขข้อยกเว้น

## กฎการเลือก

| ID | เงื่อนไข | วิธี | อ้างอิง |
|----|----------|------|---------|
| R1 | วงเงิน <= 500,000 | เฉพาะเจาะจง | กฎกระทรวง + ม.56(2)(ข) |
| R2 | วงเงิน > 500,000 ปกติ | ประกาศเชิญชวนทั่วไป | ม.55(1), 56 วรรคแรก |
| R3 | ประกาศแล้วไม่มีผู้ยื่น | คัดเลือก | ม.56(1)(ก) |
| R4 | คุณลักษณะเฉพาะ/ฝีมือเฉพาะ | คัดเลือก | ม.56(1)(ข) |
| R5 | เร่งด่วน (ไม่ใช่ฉุกเฉิน) | คัดเลือก | ม.56(1)(ค) |
| R6 | ต้องระบุยี่ห้อเฉพาะ | คัดเลือก | ม.56(1)(ง) |
| R7 | ซื้อจากต่างประเทศ | คัดเลือก | ม.56(1)(จ) |
| R8 | ฉุกเฉินถึงชีวิต/ภัยพิบัติ | เฉพาะเจาะจง | ม.56(2)(ค) |
| R9 | ผู้ขายรายเดียว | เฉพาะเจาะจง | ม.56(2)(ง) |
| R10 | หน่วยงานรัฐ/รัฐวิสาหกิจ | เฉพาะเจาะจง | ม.56(2)(จ) |

## วิธีย่อย (กรณีประกาศเชิญชวนทั่วไป)

| เงื่อนไข | วิธีย่อย |
|----------|---------|
| e-catalog + 500K-5M | e-market (ใบเสนอราคา) |
| e-catalog + > 5M | e-market (ประมูล) |
| ไม่อยู่ e-catalog + > 500K | e-bidding |
| ไม่มี internet + 500K-5M | สอบราคา |
