# คู่มือภาษาราชการสำหรับ TOR

## คำศัพท์

| ใช้ | ห้ามใช้ |
|-----|--------|
| ดำเนินการ | ทำ |
| จัดซื้อจัดจ้าง | ซื้อ/จ้าง |
| ผู้ยื่นข้อเสนอ | ผู้ขาย/ร้าน |
| กำหนดส่งมอบ | เดดไลน์ |
| ให้แล้วเสร็จภายใน | ต้องเสร็จใน |
| เป็นจำนวนเงินทั้งสิ้น | รวมเป็นเงิน |
| พัสดุ | ของ/สิ่งของ |
| ผู้รับจ้าง | ผู้รับเหมา |
| คณะกรรมการตรวจรับพัสดุ | กรรมการรับของ |
| มีความประสงค์จะ | ต้องการจะ |

## สำนวนมาตรฐาน

เปิดต้น: "ด้วย [หน่วยงาน] มีความประสงค์จะ..."
เงิน: "เป็นจำนวนเงินทั้งสิ้น X บาท (ตัวอักษร) รวมภาษีมูลค่าเพิ่มและค่าใช้จ่ายทั้งปวงแล้ว"
เวลา: "ภายในระยะเวลา X วัน นับถัดจากวันลงนามในสัญญา"
ค่าปรับ: "ชำระค่าปรับเป็นรายวัน ในอัตราร้อยละ X ของราคา..."
กฎหมาย: "ตามพระราชบัญญัติการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. ๒๕๖๐"

## ตัวเลข
- เลขไทย (๑)(๒)(๓): อ้างมาตรากฎหมาย
- เลขอารบิก 1. 2. 3.: หัวข้อ TOR
- วงเงิน: ตัวเลข + ตัวอักษร เช่น "500,000 บาท (ห้าแสนบาทถ้วน)"
