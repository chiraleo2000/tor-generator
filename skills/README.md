# Skills — offline TOR packs

Claude, ChatGPT, Gemini, and Hermes skill packs for drafting/reviewing TOR **without** the Docker web stack. They are not loaded by FastAPI or Next.js.

| Path | Role |
|------|------|
| `Draft-TORs-Skills/` | Draft TOR (intake + writing) |
| `check-TORs-Skills/` | Review TOR checklists |

In-IDE Kiro skills remain at `../.kiro/skills/` — see [SKILLS.md](../SKILLS.md).

Knowledge source for conversions: `../documents/knowledge-base/` via `Draft-TORs-Skills/convert_kb_to_markdown.py`.
