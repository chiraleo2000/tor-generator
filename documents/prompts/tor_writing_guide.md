# คู่มือการเขียน TOR ด้วยภาษาราชการ

## หลักการใช้ภาษาราชการในการร่าง TOR

### 1. หลักภาษาราชการ
- ใช้ภาษาที่สุภาพ เป็นทางการ กระชับ ชัดเจน ไม่กำกวม
- ใช้คำราชการ ไม่ใช้ภาษาพูด/ภาษาปาก
- ใช้ประโยคสมบูรณ์ มีประธาน กริยา กรรม ครบถ้วน
- หลีกเลี่ยงคำฟุ่มเฟือย ใช้คำที่จำเป็นเท่านั้น
- ใช้ศัพท์เทคนิคทางกฎหมายที่ถูกต้อง

### 2. คำศัพท์ราชการที่ต้องใช้ (ห้ามใช้คำภาษาพูด)

| ใช้ (ราชการ) | ห้ามใช้ (ภาษาพูด) |
|-------------|-------------------|
| ดำเนินการ | ทำ |
| จัดซื้อจัดจ้าง | ซื้อ/จ้าง |
| ผู้ยื่นข้อเสนอ | คนขาย/ร้าน |
| หน่วยงานของรัฐ | หน่วยงาน/ออฟฟิศ |
| คุณสมบัติ | คุณสมบัติ (ถูกแล้ว) |
| กำหนดส่งมอบ | เดดไลน์ |
| ตามที่กำหนดไว้ | ตามที่บอก |
| ให้แล้วเสร็จภายใน | ต้องเสร็จใน |
| เป็นจำนวนเงินทั้งสิ้น | รวมเป็นเงิน |
| อาศัยอำนาจตามความใน | ตาม |
| คณะกรรมการพิจารณาผล | กรรมการตัดสิน |
| ผู้มีอำนาจอนุมัติ | คนอนุมัติ |
| พัสดุ | ของ/สิ่งของ |
| ข้อตกลงเป็นหนังสือ | สัญญา (กรณีวงเงินน้อย) |
| สิ้นสุดระยะเวลา | หมดเวลา |

### 3. โครงสร้างประโยคภาษาราชการ

**รูปแบบมาตรฐาน:**
- "หน่วยงาน + มีความประสงค์ + จะ + กริยา + กรรม"
- "ผู้ยื่นข้อเสนอ + ต้อง + เงื่อนไข"
- "ให้ + ผู้รับจ้าง + ดำเนินการ + รายละเอียด + ภายในระยะเวลา"

**ตัวอย่างประโยค:**
- ✓ "สำนักงาน ก.พ.ร. มีความประสงค์จะจ้างพัฒนาระบบสารสนเทศเพื่อรองรับการปฏิบัติงาน"
- ✗ "ก.พ.ร. ต้องการจ้างทำระบบ IT"

- ✓ "ผู้ยื่นข้อเสนอต้องเป็นนิติบุคคลที่จดทะเบียนในประเทศไทย"
- ✗ "ต้องเป็นบริษัทไทย"

- ✓ "ให้ผู้รับจ้างดำเนินการส่งมอบงานงวดที่ 1 ภายในระยะเวลา 60 วัน นับถัดจากวันลงนามในสัญญา"
- ✗ "ส่งงานงวดแรกภายใน 60 วันหลังเซ็นสัญญา"

### 4. แนวทางการเขียนแต่ละหัวข้อ TOR

#### 4.1 ความเป็นมา/หลักการและเหตุผล
**วัตถุประสงค์ของหัวข้อ:** แสดงเหตุผลความจำเป็นที่ต้องจัดซื้อจัดจ้าง

**โครงสร้างการเขียน:**
1. บริบท/สภาพปัญหาปัจจุบัน
2. ความจำเป็นที่ต้องดำเนินการ
3. ความเชื่อมโยงกับภารกิจ/แผนงาน/นโยบาย
4. ผลที่คาดว่าจะได้รับ

**ตัวอย่างภาษาราชการ:**
```
ด้วย [ชื่อหน่วยงาน] มีภารกิจในการ [ภารกิจ] ตามพระราชบัญญัติ/กฎหมาย/ระเบียบ [อ้างอิง]
ปัจจุบัน [สภาพปัญหา/ข้อจำกัด] ส่งผลให้ [ผลกระทบ] ดังนั้น เพื่อ [วัตถุประสงค์] 
จึงมีความจำเป็นต้องดำเนินการจ้าง [ลักษณะงาน] เพื่อ [ผลที่คาดหวัง]
```

#### 4.2 วัตถุประสงค์
**วัตถุประสงค์ของหัวข้อ:** ระบุผลสำเร็จที่หน่วยงานต้องการ

**หลักการเขียน:**
- ใช้กริยาที่วัดผลได้: "เพื่อให้มี" "เพื่อจัดหา" "เพื่อพัฒนา" "เพื่อปรับปรุง"
- สอดคล้องกับความเป็นมา
- เขียนเป็นข้อ ๆ

**ตัวอย่าง:**
```
การจ้างครั้งนี้มีวัตถุประสงค์ ดังนี้
    ๒.๑ เพื่อให้มีระบบสารสนเทศที่รองรับการปฏิบัติงานของหน่วยงาน
    ๒.๒ เพื่อเพิ่มประสิทธิภาพในการให้บริการประชาชน
    ๒.๓ เพื่อลดระยะเวลาและขั้นตอนการดำเนินงาน
```

#### 4.3 คุณสมบัติของผู้ยื่นข้อเสนอ
**วัตถุประสงค์ของหัวข้อ:** กำหนดคุณสมบัติผู้มีสิทธิเข้าเสนอราคา

**คุณสมบัติบังคับตามกฎหมาย (ต้องมีทุก TOR):**
```
ผู้ยื่นข้อเสนอต้องมีคุณสมบัติ ดังต่อไปนี้
    (๑) มีความสามารถตามกฎหมาย
    (๒) ไม่เป็นบุคคลล้มละลาย
    (๓) ไม่อยู่ระหว่างเลิกกิจการ
    (๔) ไม่เป็นบุคคลซึ่งอยู่ระหว่างถูกระงับการยื่นข้อเสนอหรือทำสัญญา
        กับหน่วยงานของรัฐไว้ชั่วคราว ตามที่ประกาศเผยแพร่ในระบบเครือข่าย
        สารสนเทศของกรมบัญชีกลาง
    (๕) ไม่เป็นบุคคลซึ่งถูกระบุชื่อไว้ในบัญชีรายชื่อผู้ทิ้งงาน
        และได้แจ้งเวียนชื่อให้เป็นผู้ทิ้งงานของหน่วยงานของรัฐ
        ในระบบเครือข่ายสารสนเทศของกรมบัญชีกลาง
    (๖) มีคุณสมบัติและไม่มีลักษณะต้องห้ามตามที่คณะกรรมการนโยบาย
        การจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐกำหนดในราชกิจจานุเบกษา
    (๗) เป็นบุคคลธรรมดาหรือนิติบุคคลผู้มีอาชีพรับจ้างงานดังกล่าว
    (๘) ไม่เป็นผู้มีผลประโยชน์ร่วมกันกับผู้ยื่นข้อเสนอรายอื่น
        ที่เข้ายื่นข้อเสนอให้แก่ [หน่วยงาน] ณ วันประกาศ [วิธีจัดซื้อ]
    (๙) ไม่เป็นผู้ได้รับเอกสิทธิ์หรือความคุ้มกัน ซึ่งอาจปฏิเสธไม่ยอม
        ขึ้นศาลไทย เว้นแต่รัฐบาลของผู้ยื่นข้อเสนอได้มีคำสั่งให้สละ
        เอกสิทธิ์และความคุ้มกันเช่นว่านั้น
```

#### 4.4 ขอบเขตของงาน
**วัตถุประสงค์:** กำหนดรายละเอียดงานที่ต้องดำเนินการ

**หลักการเขียน:**
- ระบุรายละเอียดให้ชัดเจน ครบถ้วน วัดผลได้
- ใช้ภาษาที่ไม่กำกวม ไม่เปิดช่องให้ตีความได้หลายทาง
- แยกเป็นข้อ/หัวข้อย่อยตามลักษณะงาน

**สำนวนที่ใช้:**
```
ผู้รับจ้างต้องดำเนินการ ดังต่อไปนี้
    ๔.๑ [หมวดงาน]
        ๔.๑.๑ [รายละเอียดงาน — ระบุปริมาณ/ขนาด/จำนวนให้ชัดเจน]
        ๔.๑.๒ [รายละเอียดงาน]
    ๔.๒ [หมวดงาน]
```

#### 4.5 ระยะเวลาดำเนินการ
**สำนวนมาตรฐาน:**
```
กำหนดระยะเวลาดำเนินการ [จำนวน] วัน นับถัดจากวันลงนามในสัญญา
หรือนับถัดจากวันที่ได้รับหนังสือแจ้งจาก [หน่วยงาน] ให้เริ่มทำงาน
```

#### 4.6 วงเงินงบประมาณ
**สำนวนมาตรฐาน:**
```
วงเงินงบประมาณ/วงเงินที่ได้รับจัดสรร เป็นจำนวนเงินทั้งสิ้น [จำนวน] บาท
([ตัวอักษร]) รวมภาษีมูลค่าเพิ่มและค่าใช้จ่ายทั้งปวงแล้ว
```

#### 4.7 งวดงาน การส่งมอบ และการจ่ายเงิน
**สำนวนมาตรฐาน:**
```
แบ่งการส่งมอบงานและการจ่ายเงินออกเป็น [จำนวน] งวด ดังนี้

งวดที่ ๑ (ร้อยละ [X] ของวงเงินค่าจ้าง เป็นจำนวนเงิน [Y] บาท)
    ผู้รับจ้างต้องดำเนินการ [รายละเอียดงาน] ให้แล้วเสร็จ
    ภายในระยะเวลา [จำนวน] วัน นับถัดจากวันลงนามในสัญญา
    โดยส่งมอบ [deliverables] ดังนี้
    - [รายการ ๑]
    - [รายการ ๒]
```

#### 4.8 อัตราค่าปรับ
**สำนวนมาตรฐาน (ส่งมอบทั้งหมดพร้อมกัน):**
```
หากผู้รับจ้างไม่สามารถส่งมอบงานได้ตามกำหนดเวลา ผู้รับจ้างต้องชำระ
ค่าปรับเป็นรายวัน ในอัตราร้อยละ [0.01-0.10] ของราคางานจ้างตามสัญญา
แต่ต้องไม่ต่ำกว่าวันละ ๑๐๐ บาท
```

**สำนวนมาตรฐาน (ส่งมอบแยกส่วน):**
```
หากผู้รับจ้างไม่สามารถส่งมอบพัสดุได้ตามกำหนดเวลา ผู้รับจ้างต้องชำระ
ค่าปรับเป็นรายวัน ในอัตราร้อยละ [0.01-0.20] ของราคาพัสดุที่ยังไม่ได้รับมอบ
แต่ต้องไม่ต่ำกว่าวันละ ๑๐๐ บาท
```

#### 4.9 หลักประกันสัญญา
**สำนวนมาตรฐาน:**
```
ผู้ชนะการจัดจ้างต้องวางหลักประกันสัญญาเป็นจำนวนเงินเท่ากับร้อยละ ๕
ของราคาค่าจ้างตามสัญญา โดยใช้หลักประกันอย่างหนึ่งอย่างใด ดังต่อไปนี้
    (๑) เงินสด
    (๒) เช็คหรือดราฟท์ที่ธนาคารเป็นผู้สั่งจ่าย
    (๓) หนังสือค้ำประกันของธนาคารภายในประเทศ
    (๔) หนังสือค้ำประกันอิเล็กทรอนิกส์ของธนาคารภายในประเทศ
    (๕) พันธบัตรรัฐบาลไทย
```

#### 4.10 หลักเกณฑ์การพิจารณาคัดเลือกข้อเสนอ
**สำนวนสำหรับเกณฑ์ราคาต่ำสุด:**
```
การพิจารณาคัดเลือกข้อเสนอ ใช้เกณฑ์ราคา โดยพิจารณาจากราคารวม
ที่ผู้ยื่นข้อเสนอเสนอราคาต่ำสุด และต้องไม่สูงกว่าวงเงินงบประมาณ
ที่ตั้งไว้ และเป็นราคาที่เหมาะสมกับสภาวการณ์ในขณะนั้น
```

**สำนวนสำหรับ Price Performance:**
```
การพิจารณาคัดเลือกข้อเสนอ ใช้เกณฑ์ราคาประกอบเกณฑ์อื่น
โดยกำหนดน้ำหนักคะแนน ดังนี้
    - ข้อเสนอด้านเทคนิค   ร้อยละ [X]
    - ข้อเสนอด้านราคา     ร้อยละ [Y]
รวม                       ร้อยละ ๑๐๐

เกณฑ์การพิจารณาข้อเสนอด้านเทคนิค ประกอบด้วย
    (๑) [หัวข้อ]          [คะแนน] คะแนน
    (๒) [หัวข้อ]          [คะแนน] คะแนน
    รวม                   [คะแนนเต็ม] คะแนน

ทั้งนี้ ผู้ยื่นข้อเสนอต้องได้คะแนนด้านเทคนิครวมไม่ต่ำกว่าร้อยละ [70-80]
ของคะแนนเต็มด้านเทคนิค จึงจะได้รับการพิจารณาข้อเสนอด้านราคาต่อไป
```

### 5. สำนวนราชการที่ใช้บ่อยใน TOR

#### การอ้างอิงกฎหมาย:
- "ตามพระราชบัญญัติการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. ๒๕๖๐"
- "ตามระเบียบกระทรวงการคลังว่าด้วยการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. ๒๕๖๐"
- "ตามกฎกระทรวงกำหนด..."
- "อาศัยอำนาจตามความในมาตรา..."
- "โดยอนุโลมตาม..."

#### การกำหนดเงื่อนไข:
- "ทั้งนี้" = นอกจากนี้/เพิ่มเติม
- "เว้นแต่" = ยกเว้นกรณี
- "ตามแต่กรณี" = ขึ้นอยู่กับสถานการณ์
- "โดยอนุโลม" = นำมาใช้โดยปรับให้เหมาะสม
- "ให้เป็นไปตามที่ [ผู้มีอำนาจ] กำหนด"
- "ภายใต้บังคับแห่ง [กฎหมาย]"

#### การระบุข้อห้าม:
- "ผู้ยื่นข้อเสนอต้องไม่เป็น..."
- "ห้ามมิให้..."
- "ไม่อนุญาตให้..."
- "ผู้รับจ้างจะนำงานทั้งหมดหรือแต่บางส่วนไปจ้างช่วงให้ผู้อื่นทำแทนมิได้"

#### การระบุระยะเวลา:
- "ภายในระยะเวลา [X] วัน นับถัดจากวัน..."
- "ภายใน [X] วันทำการ นับถัดจากวัน..."
- "ไม่น้อยกว่า [X] วัน ก่อนวัน..."
- "ให้แล้วเสร็จภายในวันที่..."

#### การระบุจำนวนเงิน:
- "เป็นจำนวนเงินทั้งสิ้น [ตัวเลข] บาท ([ตัวอักษร])"
- "รวมภาษีมูลค่าเพิ่มและค่าใช้จ่ายทั้งปวงแล้ว"
- "ในอัตราร้อยละ..."
- "ไม่เกินร้อยละ..."

### 6. ข้อพึงระวังในการเขียน TOR

#### ห้ามทำ:
- ห้ามใช้ภาษาไม่เป็นทางการ คำย่อที่ไม่เป็นมาตรฐาน
- ห้ามระบุยี่ห้อสินค้า เว้นแต่เป็นงานซ่อมที่ต้องใช้อะไหล่ยี่ห้อเดียวกัน
- ห้ามกำหนดคุณสมบัติที่เป็นการกีดกันหรือเอื้อประโยชน์
- ห้ามกำหนดเงื่อนไขที่เป็นไปไม่ได้ในทางปฏิบัติ
- ห้ามใช้คำว่า "หรือเทียบเท่า" โดยไม่ระบุ spec ที่เทียบเท่า
- ห้ามแบ่งซื้อ/แบ่งจ้างเพื่อหลีกเลี่ยงวิธีจัดซื้อที่กำหนด

#### ต้องมี:
- ต้องอ้างอิงกฎหมาย/ระเบียบที่เกี่ยวข้อง
- ต้องใช้เลขไทย (๑, ๒, ๓) สำหรับลำดับข้อกฎหมาย
- ต้องใช้เลขอารบิก (1, 2, 3) สำหรับจำนวน/ปริมาณ
- ต้องระบุ "รวมภาษีมูลค่าเพิ่มแล้ว" เมื่อระบุวงเงิน
- ต้องใช้คำว่า "วันทำการ" หรือ "วัน" ให้ชัดเจน
- ต้องระบุเลขที่เอกสาร วันที่ หน่วยงาน ให้ครบถ้วน

### 7. การเรียงลำดับเลข

**ข้อกฎหมาย/ข้อบังคับ:** ใช้เลขไทย (๑) (๒) (๓)
**หัวข้อ TOR:** ใช้เลขอารบิก 1. 2. 3. หรือ ๑. ๒. ๓.
**หัวข้อย่อย:** 1.1, 1.2 หรือ ๑.๑, ๑.๒
**รายการ:** (ก) (ข) (ค) หรือ - (ขีด)
