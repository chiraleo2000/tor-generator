# บันทึกแหล่งข้อมูลภายนอก

## งานที่ 4: แหล่งข้อมูลภายนอก

### สถานะ: ข้อมูลภายในประมาณ 26 ไฟล์เพียงพอสำหรับคลังความรู้เบื้องต้น

คลังที่แอปใช้จริงคือ PDF ใน `documents/sources/` (คู่มือแนวปฏิบัติ + ข้อมูลดิบ) ไม่ใช่ไฟล์ JSON ในโฟลเดอร์นี้

### แหล่งที่ควรเสริมในอนาคต (เมื่อมีเครดิต API / สิทธิ์ดาวน์โหลด):

1. **กรมบัญชีกลาง (CGD)** — www.cgd.go.th
   - หนังสือเวียน กวจ. ฉบับล่าสุดหลัง พ.ศ. 2560
   - ประกาศคณะกรรมการนโยบายฯ
   - คำถามที่พบบ่อยเรื่องการจัดซื้อจัดจ้าง

2. **ระบบ e-GP** — www.gprocurement.go.th
   - ตัวอย่าง TOR ที่ประกาศจริง
   - แนวทางการใช้งานระบบ

3. **สำนักงานพัฒนารัฐบาลดิจิทัล (DGA)** — www.dga.or.th
   - มาตรฐาน TOR สำหรับงานไอที/ดิจิทัลภาครัฐ
   - แนวทางจัดซื้อคลาวด์/ซอฟต์แวร์บริการ
   - พบ: กำหนดแบบคำขอขึ้นทะเบียนตำรับและใบแทน ยส3 วช3/4 2567

4. **สำนักงบประมาณ**
   - เกณฑ์ราคากลางไอซีที
   - บัญชีราคามาตรฐานครุภัณฑ์

5. **สตง.** — สำนักงานการตรวจเงินแผ่นดิน
   - แนวทาง/ข้อสังเกตจากการตรวจสอบ

6. **กฎกระทรวงฉบับใหม่ที่พบ:**
   - กฎกระทรวงกำหนดเรื่องการจัดซื้อจัดจ้างกับหน่วยงานของรัฐที่ใช้สิทธิอุทธรณ์ไม่ได้ พ.ศ. **2568** (มีอยู่ในข้อมูลดิบแล้ว)

### ข้อสังเกต:
- ไม่พบการแก้ไข/ยกเลิก พ.ร.บ. 2560 หรือระเบียบ 2560 — ยังบังคับใช้อยู่
- กฎกระทรวงกำหนดวงเงินเฉพาะเจาะจง (ไม่เกิน 500,000 บาท) ยังไม่มีการปรับปรุง
- ข้อมูลภายในที่มี (PDF + DOCX ประมาณ 26 ไฟล์) ครอบคลุมเพียงพอสำหรับระยะแรก
