# External Sources Note

## Task 4: แหล่งข้อมูลภายนอก

### สถานะ: ข้อมูล 26 ไฟล์ภายในเพียงพอสำหรับ Knowledge Base เบื้องต้น

### แหล่งที่ควรเสริมในอนาคต (เมื่อมี API credit / manual access):

1. **กรมบัญชีกลาง (CGD)** — www.cgd.go.th
   - หนังสือเวียน กวจ. ฉบับล่าสุดหลัง 2560
   - ประกาศคณะกรรมการนโยบายฯ
   - FAQ การจัดซื้อจัดจ้าง

2. **ระบบ e-GP** — www.gprocurement.go.th
   - ตัวอย่าง TOR ที่ประกาศจริง
   - แนวทางการใช้งานระบบ

3. **สำนักงานพัฒนารัฐบาลดิจิทัล (DGA)** — www.dga.or.th
   - มาตรฐาน TOR สำหรับงาน IT/Digital ภาครัฐ
   - แนวทางจัดซื้อ Cloud/SaaS
   - พบ: กำหนดแบบคำขอขึ้นทะเบียนตำรับและใบแทน ยส3 วช3/4 2567

4. **สำนักงบประมาณ**
   - เกณฑ์ราคากลาง ICT
   - บัญชีราคามาตรฐานครุภัณฑ์

5. **สตง.** — สำนักงานการตรวจเงินแผ่นดิน
   - แนวทาง/ข้อสังเกตจากการตรวจสอบ

6. **กฎกระทรวงฉบับใหม่ที่พบ:**
   - กฎกระทรวงกำหนดเรื่องการจัดซื้อจัดจ้างกับหน่วยงานของรัฐที่ใช้สิทธิอุทธรณ์ไม่ได้ พ.ศ. **2568** (มีอยู่ในข้อมูลดิบแล้ว)

### ข้อสังเกต:
- ไม่พบการแก้ไข/ยกเลิก พ.ร.บ. 2560 หรือระเบียบ 2560 — ยังบังคับใช้อยู่
- กฎกระทรวงกำหนดวงเงินเฉพาะเจาะจง (≤500,000 บาท) ยังไม่มีการปรับปรุง
- ข้อมูลภายในที่มี (26 PDF + DOCX) ครอบคลุมเพียงพอสำหรับ phase แรก
